Cara Kerja Sinkronisasi Tanpa Database:
Saat Anda mengedit atau menambah produk di browser ini, perubahan langsung aktif secara instan dan tersimpan di LocalStorage. Agar perubahan ini permanen dan dapat dilihat oleh seluruh pembeli di dunia melalui GitHub Pages, Anda hanya perlu mengunduh file site-data.json baru dan menaruhnya di repositori GitHub Anda!

Langkah 1: Ekspor Data Terbaru

Klik tombol di bawah untuk mendownload file site-data.json dengan produk dan pengaturan profil terbaru yang sudah Anda input:

Langkah 2: Cara Publish ke GitHub Pages (1 Menit)

  1. Buka akun GitHub Anda dan buat repository baru (misal: katalog-umkm) dengan status Public.
  2. Upload seluruh file website ini (index.html, folder css, folder js, dan file data/site-data.json).
  3. Masuk ke menu tab Settings di repository GitHub Anda → pilih menu Pages di bilah samping kiri.
  4. Pada bagian Build and deployment > Source, pilih Deploy from a branch.
  5. Pilih branch main (atau master) dan folder /(root), lalu klik tombol Save.
  6. Tunggu 30-60 detik. Website Anda akan langsung online dan memiliki alamat publik HTTPS gratis seperti:
    https://username.github.io/katalog-umkm/
